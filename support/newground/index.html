New Ground records the route you walk and draws the ground you have covered from it. If something is not working, or the app did something you did not expect, write to us — a person reads it. New Ground은 걸은 경로를 기록하고 그로부터 차지한 영역을 그립니다. 동작이 이상하거나 예상과 다른 일이 생기면 메일을 주세요. 사람이 읽습니다.

Requirements / 요구 사양

iOS 16.4 or later / 16.4 이상
Android 7.0 (API 24) or later / 7.0 이상

The map is blank or grey / 지도가 비어 있어요

The route is still being recorded. The map underneath it is drawn from tiles fetched over the network, so a weak connection leaves the lines on an empty background. If it stays empty on a good connection, tell us — that one is ours, not yours. 경로 기록은 정상입니다. 지도는 네트워크로 받아온 타일로 그려지기 때문에, 연결이 약하면 선만 남고 배경이 비어 보입니다. 연결이 멀쩡한데도 계속 비어 있으면 알려 주세요. 그건 저희 쪽 문제입니다.

Recording stopped when the screen turned off / 화면을 끄니 기록이 멈췄어요

That is the background location permission. New Ground asks for it after you start your first recording, and without it a walk is only recorded while the app is on screen. You can grant it later in the system settings: Location → Allow all the time. 배경 위치 권한 문제입니다. New Ground은 첫 기록을 시작한 뒤에 이 권한을 요청하고, 허용하지 않으면 앱이 화면에 떠 있는 동안에만 기록합니다. 나중에 시스템 설정에서 위치 → 항상 허용으로 바꿀 수 있습니다.

Walking the same street twice adds nothing / 같은 길을 두 번 걸어도 늘지 않아요

That is deliberate. The shape does not remember how often each part was walked, so the second lap is free and there is nothing to farm. 의도한 동작입니다. 각 구간을 몇 번 걸었는지는 모양에 남지 않습니다. 두 번째 바퀴는 공짜이고, 반복해서 쌓을 것도 없습니다.

I deleted a walk but my ground did not shrink / 산책을 지웠는데 영역이 그대로예요

Also deliberate, and worth knowing before you delete anything. The ground is built by folding each finished walk into the shape already held, so it does not remember which part came from which walk. Deleting a walk removes the walk; it cannot subtract the ground. To clear the ground as well, uninstall the app. 이것도 의도한 동작이고, 지우기 전에 알아 두시는 편이 좋습니다. 영역은 끝난 산책을 기존 모양에 접어 넣는 방식으로 만들어지기 때문에, 어느 부분이 어느 산책에서 왔는지 기억하지 않습니다. 산책을 지우면 산책만 사라지고 영역은 빼낼 수 없습니다. 영역까지 지우려면 앱을 삭제하세요.

How do I delete everything? / 전부 지우려면?

Uninstall the app. Everything lives in a database inside your device that only this app can open, and it goes with the app. 앱을 삭제하시면 됩니다. 모든 데이터는 이 앱만 열 수 있는 기기 내부 데이터베이스에 있고, 앱과 함께 사라집니다.

Does my route leave the phone? / 경로가 기기를 떠나나요?

No. There is no account and no server to upload it to. The one thing that does go out is the request for map tiles, which tells Google which area of the map is on screen — not where you walked. The privacy policy sets out exactly what that carries. 아니요. 계정도, 올릴 서버도 없습니다. 밖으로 나가는 것은 지도 타일 요청뿐이고, 그것은 화면에 보이는 지도 영역을 Google에 알릴 뿐 걸은 경로를 알리지 않습니다. 무엇이 실리는지는 개인정보처리방침에 그대로 적어 두었습니다.
